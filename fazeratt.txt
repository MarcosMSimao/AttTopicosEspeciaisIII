Resolver conflito do Postgres (duas opções)
Opção A (usar o Postgres do projetoWeb para ambos): editar URL do aulaSpring para apontar para localhost:5432

''''properties
# filepath: aulaSpring/projeto/src/main/resources/application.properties
# ...existing code...
spring.datasource.url=jdbc:postgresql://localhost:5432/bd_spring
# ...existing code...
''''

Opção B (mudar mapeamento de porta do Postgres em aulaSpring): alterar docker-compose do aulaSpring

''''yaml
# filepath: aulaSpring/docker-compose.yml
# ...existing code...
services:
  postgres:
    image: postgres:15
    container_name: postgres_spring3
    restart: always
    environment:
      POSTGRES_USER: root
      POSTGRES_PASSWORD: root
      POSTGRES_DB: bd_spring
    ports:
      - "5433:5432"    # alterado para evitar conflito
    volumes:
      - postgres-data:/var/lib/postgresql/data
# ...existing code...
''''
